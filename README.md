# Predicting_Passenger_Flow_in_Autonomous_Transport

## Overview

This project implements a predictive analytics model to estimate passenger crowd levels in autonomous public transport systems. It integrates a Hidden Markov Model (HMM) for passenger behavior analysis and Fuzzy Logic for decision-making, leveraging real-time boarding and alighting data.

## Features

- Simulates passenger boarding and alighting behavior.

- Applies Hidden Markov Models (HMM) to predict passenger flow patterns.

- Uses Fuzzy Logic to classify crowd levels (Low, Medium, High).

- Provides real-time visualization of predicted crowd levels.

## Technologies Used

- Python (Primary programming language)

- NumPy & Pandas (Data handling and processing)

- Matplotlib (Data visualization)

- hmmlearn (Hidden Markov Models for sequence prediction)

- scikit-fuzzy (Fuzzy Logic system for crowd classification)

## Installation

- Ensure you have Python installed, then install the required dependencies:

- pip install numpy pandas matplotlib hmmlearn scikit-fuzzy

## Usage

- Run the script to generate passenger flow predictions:

- Predicting_Passenger_Flow_in_Autonomous_Transport.ipynb 

## Output

- A graph displaying predicted crowd levels over time.

- Identifies trends in boarding and alighting patterns using HMM and Fuzzy Logic.
